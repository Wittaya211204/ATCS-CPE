# LAB03 – RAG ถาม-ตอบรัฐธรรมนูญไทย (2540 / 2550 / 2560)

ต่อยอดจากระบบ RAG ใน LAB02 (Embedding + FAISS + Hybrid BM25 + LLM) โดยเปลี่ยนคลังความรู้เป็น **รัฐธรรมนูญแห่งราชอาณาจักรไทย 3 ฉบับ** และปรับ pipeline ให้เหมาะกับเอกสารกฎหมายภาษาไทย ซึ่งมีปัญหาที่ข้อมูลของ LAB02 ไม่มี ได้แก่ ข้อความเกือบทั้งหมดเป็นภาษาไทยไม่มีช่องว่างระหว่างคำ, ใช้เลขไทย, มีโครงสร้างหมวด/มาตรา และมีหลายฉบับที่เนื้อหาคล้ายกัน

## สิ่งที่เปลี่ยนจาก LAB02

| ส่วน | LAB02 | LAB03 | ไฟล์ |
|---|---|---|---|
| Chunking | ตัดตามย่อหน้า + จำนวนตัวอักษร | ตัดตาม **มาตรา** (1 chunk = 1 มาตรา) มาตราที่ยาวเกิน 1,200 ตัวอักษรค่อยแบ่งย่อย ทุก chunk มีหัว `[รัฐธรรมนูญ 2560 \| หมวด 3 ... \| มาตรา 34]` และ metadata ปี/หมวด/มาตรา | `src/chunking.py` |
| ตัวเลข | – | แปลงเลขไทย → อารบิกทั้งเอกสารและคำถาม (`มาตรา ๓๔` = `มาตรา 34`) | `src/chunking.py`, `src/retriever.py` |
| BM25 tokenizer | `text.split()` | ตัดคำด้วย PyThaiNLP `newmm` + ตัด stopwords | `src/retriever.py` |
| ค้นหามาตราตรง ๆ | – | คำถามที่ระบุ "มาตรา N" ดึง chunk ของมาตรานั้นมาเป็นอันดับแรกจาก metadata | `src/retriever.py` |
| แยกฉบับปี | – | ถ้าคำถามระบุปี (2540/2550/2560) ค้นเฉพาะฉบับนั้น ถ้าไม่ระบุใช้ 2560 | `src/retriever.py` |
| Hybrid | ใช้ BM25 re-rank เฉพาะผลจาก vector | ให้คะแนนทุก chunk ของฉบับนั้นทั้งสองวิธีแล้วรวมกัน BM25 จึงดึงผลที่ vector พลาดได้ | `src/retriever.py`, `src/embedding_store.py` |
| Embedding | `nomic-embed-text` (768 มิติ) | `bge-m3` (รองรับหลายภาษา, 1024 มิติ) และตรวจขนาดเวกเตอร์จริงจากโมเดลแทนการ hard-code | `src/config.py`, `src/embedding_store.py` |
| Prompt | อ้างอิงชื่อไฟล์ | อ้างอิง "รัฐธรรมนูญ ปี มาตรา N" และห้ามปนต่างฉบับ | `src/generator.py` |

## ผลการทดลอง

### 1. Chunking ตามโครงสร้าง (`evaluate.py structure`)

| ฉบับ | มาตราที่แยกได้ | จำนวนจริง | chunk ทั้งหมด |
|---|---|---|---|
| 2540 | 336 | 336 | 374 |
| 2550 | 309 | 309 | 365 |
| 2560 | 279 | 279 | 342 |

แยกมาตราได้ครบทุกฉบับ จำนวน chunk มากกว่ามาตราเพราะมาตราที่ยาวเกิน 1,200 ตัวอักษรถูกแบ่งย่อย

### 2. ค้นหามาตราและฉบับปี (`evaluate.py lookup`)

| คำถาม | ผลอันดับ 1 |
|---|---|
| มาตรา 34 ว่าอย่างไร | รัฐธรรมนูญ 2560 หมวด 3 มาตรา 34 |
| รัฐธรรมนูญ 2550 มาตรา 45 ว่าอย่างไร | รัฐธรรมนูญ 2550 หมวด 3 มาตรา 45 |
| รัฐธรรมนูญ ๒๕๔๐ มาตรา ๑ (เลขไทย) | รัฐธรรมนูญ 2540 หมวด 1 มาตรา 1 |

### 3. Retrieval benchmark (`evaluate.py retrieval`)

ใช้คำถาม 18 ข้อที่ **เรียบเรียงใหม่ ไม่คัดลอกจากตัวบท** (เช่น "ประชาชนรวมตัวกันประท้วงโดยสงบได้หรือไม่" → มาตรา 44) และตรวจแล้วว่าคำตอบอยู่ในมาตราเฉลยจริง ทดสอบเฉพาะส่วน BM25 บนฉบับ 2560 นับว่าเจอเมื่อ chunk ที่ค้นได้มีข้อความคำตอบ

| การตั้งค่า | hit@1 | hit@3 | MRR |
|---|---|---|---|
| A: smart_chunk + BM25 ตัดคำด้วยช่องว่าง (แบบ LAB02) | 0.00 | 0.00 | 0.00 |
| B: smart_chunk + BM25 ตัดคำไทย | 0.44 | 0.61 | 0.52 |
| C: legal_chunk + BM25 ตัดคำไทย (LAB03) | 0.39 | 0.72 | 0.54 |

ผลรายข้ออยู่ใน `eval/retrieval_results.json`

**วิเคราะห์ผล**

- **A ได้ 0 ทุกข้อ** BM25 ของ LAB02 ใช้ `split()` ประโยคไทยทั้งประโยคจึงกลายเป็น token เดียว ไม่มีทางตรงกับคำถามที่เรียบเรียงใหม่ ใน LAB02 ยังพอใช้ได้เพราะมีคำภาษาอังกฤษ (ชื่อแพ็กเกจ, ชื่อเมนู) ช่วยจับคู่ แต่รัฐธรรมนูญแทบเป็นภาษาไทยล้วน
- **A → B** การตัดคำไทยเป็นปัจจัยที่ทำให้ BM25 ใช้งานได้จริงกับเอกสารภาษาไทย
- **B → C** hit@3 ดีขึ้น (0.61 → 0.72) เพราะแต่ละ chunk ครบหนึ่งมาตรา ไม่ขาดกลางประโยค แต่ hit@1 ลดลงเล็กน้อย (0.44 → 0.39) บางข้อมาตราข้างเคียงที่ใช้คำคล้ายกันได้คะแนนสูงกว่า เช่น "วุฒิสภามีสมาชิกกี่คน" ได้มาตรา 116 เป็นอันดับแรก และมาตรา 107 ไม่ติด 3 อันดับแรก นอกจากนี้ chunk ยังมี metadata ปี/หมวด/มาตรา ซึ่งทำให้ lookup และการแยกฉบับใน (2) เป็นไปได้ สิ่งนี้ smart_chunk ทำไม่ได้
- ข้อที่ BM25 พลาดเป็นคำถามที่ใช้คำต่างจากตัวบท เช่น "ผู้หญิงกับผู้ชาย" กับ "ชายและหญิง" หรือ "รักษาพยาบาล" กับ "บริการสาธารณสุข" ซึ่งเป็นงานของ vector search ในโหมด hybrid

### 4. ผลกับ LLM จริง (Ollama: bge-m3 + llama3.2)

รันบน Windows ด้วย Ollama บนเครื่อง ครั้งแรกสร้าง index 1,081 vectors แล้วบันทึกลง `data/index/` ครั้งต่อไปโหลดจากดิสก์

| คำถาม | ผลค้นหา (อันดับ 1–4) | คำตอบ |
|---|---|---|
| ประชาชนมีเสรีภาพในการชุมนุมหรือไม่ | [hybrid] **2560 ม.44** (0.850), ม.34 (0.569), ม.31 (0.540), ม.25 (0.539) | ถูกต้อง: มีเสรีภาพในการชุมนุมโดยสงบและปราศจากอาวุธ อ้างอิงมาตรา 44 ฉบับ 2560 |
| รัฐธรรมนูญ 2550 มาตรา 45 ว่าอย่างไร | [section_lookup] **2550 ม.45** (1.000), ม.307 (0.735), คำปรารภ (0.593), ม.306 (0.554) | ถูกต้อง: สรุปเสรีภาพในการแสดงความคิดเห็นและข้อยกเว้นตามมาตรา 45 ฉบับ 2550 ไม่ปนกับฉบับ 2560 |

**ข้อสังเกต**
- คำถามเชิงความหมาย (ข้อ 1) มาตราที่ถูกได้คะแนนนำห่างอันดับ 2 (0.850 เทียบกับ 0.569) อันดับ 2–4 อยู่ในหมวดสิทธิเสรีภาพเดียวกัน
- คำถามที่ระบุเลขมาตรา (ข้อ 2) section lookup ดึงมาตราได้ตรงและเลือกฉบับปีถูก แต่อันดับ 2–4 ไม่เกี่ยวข้องเลย (บทเฉพาะกาล, คำปรารภ) เพราะเมื่อตัดเลขมาตราและปีออกแล้ว คำถามแทบไม่มีเนื้อหาให้ค้น ครั้งนี้ไม่กระทบคำตอบเพราะ LLM ใช้เฉพาะมาตรา 45 แต่เป็นจุดที่ควรปรับ (ดูข้อจำกัด)

## ข้อจำกัด

- benchmark ข้อ 3 วัดเฉพาะ BM25 ส่วน hybrid ทดสอบกับ LLM เพียง 2 คำถามในข้อ 4 ยังไม่ได้วัด hit@k ของ hybrid ทั้ง 18 ข้อ
- เมื่อเจอ section lookup ระบบยังเติมผลอันดับรองที่ไม่เกี่ยวข้องส่งไปให้ LLM ควรปรับให้ส่งเฉพาะมาตราที่ระบุ
- ยังไม่ได้ทดสอบคำถามที่ไม่มีคำตอบในรัฐธรรมนูญกับ LLM จริง (`python eval/evaluate.py hallucination`)
- ชุดคำถามมี 18 ข้อ ผลจึงบอกแนวโน้มได้แต่ยังไม่แม่นทางสถิติ
- การตรวจปีใช้ regex `25xx` ถ้าคำถามพูดว่า "ฉบับก่อนหน้า" ระบบจะไม่เข้าใจ
- คำตอบจากระบบนี้ใช้เพื่อการศึกษา ไม่ใช่คำปรึกษาทางกฎหมาย
